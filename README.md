# LOMBONGO — Login Practice

Projeto desenvolvido como prática de **autenticação e interface de login**, inspirado no projeto principal **Lombongo — O Mercado Digital de Angola**.

> **Nota:** Este projeto é apenas para fins de estudo e prática. Não possui backend nem base de dados real.

## Sobre o projeto

Esta versão do Lombongo foi criada para praticar a construção de um sistema de **login e criação de conta utilizando apenas tecnologias front-end**.

O objetivo principal foi compreender como funciona o fluxo básico de autenticação no lado do cliente, desde o preenchimento dos formulários até à validação e alteração do estado da interface.

## Funcionalidades

* Página de login
* Página de criação de conta
* Validação dos campos
* Alternância entre login e cadastro
* Validação de credenciais no front-end
* Simulação de sessão
* Feedback visual para erros e ações do utilizador
* Interface responsiva
* Design inspirado na identidade visual do Lombongo

## Como executar

Como este é um projeto exclusivamente front-end, não é necessário instalar servidor ou banco de dados.

### 1. Clonar o repositório

```bash

```

### 2. Entrar na pasta

```bash
cd SEU-REPOSITORIO
```

### 3. Executar

Abra o arquivo `index.html` no navegador.

Também é possível utilizar uma extensão como **Live Server** no VS Code para executar o projeto localmente.

## Limitações

Este projeto **não implementa autenticação real**.

Os dados utilizados durante o login são tratados apenas no navegador. Não existe:

* Banco de dados
* Backend
* API de autenticação
* Criptografia de senhas
* Sistema real de sessões
* Recuperação de senha

Por isso, **não deve ser utilizado em produção**.
